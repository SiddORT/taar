Build a Daily Vendor Challan module for recording vendor challans before PO creation.

This module must allow daily vendor entries for materials, artwork, outsourcing, artisans, packing, shipping, and other expenses.

Keep this module lightweight and link it to existing PO, PR, vendor ledger, and payment flow.
